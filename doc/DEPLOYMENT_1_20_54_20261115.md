## Result

Existing unpaid salaries and taxes can receive a native payment through the
same Record payment control used for invoices. Salary discovery remains
list-only; it never enters unattended/bulk matching. The guarded adapter checks
owned company/account/source/parent facts, employee visibility, exact remaining
balance, identity, dates, existing movements/payments and competing claims.
Native payment, bank attachment, paid status and audit commit together; the
statement remains pending for separate reconciliation. No parent document is
created. Retired More/skip/quick-tax/quick-supplier features remain absent.
