## Known release limitation

The pinned native-transfer hook permits the native action if its duplicate query
throws, and a failed confirmation audit is logged rather than blocking the action.
Normal-path tests therefore do not establish an unconditional duplicate-transfer
guarantee during database/audit failures. This deployment preserves the requested
release exactly; that failure behavior remains a separate source issue.
