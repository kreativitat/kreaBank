## Result

The existing-movement selector has no search or editable batch-name fields.
Save draft and Review selection retain distinct actions and icons, with short
visible labels, native hover explanations and accessible descriptions. Existing
private draft names survive requests without the removed name input. Native
header filters and the legacy workspace search remain available. The list now
defaults to ten rows; explicit native page-size choices persist.

Successful row actions retain unchanged scan summaries instead of restarting the
whole page. Per-source fingerprints, shared target dependencies and conservative
amount/currency/date peers invalidate affected results, including prior no-match
rows. Prepared display envelopes cover only one current native page, expire at
a fixed 120 seconds, and require one-use continuation after an action or completed
scan. Context binds actor, company, filters, effective permissions, salary employee
scope and matching policy. Current target ownership/visibility is checked before
reuse. Ordinary refresh recomputes visible recommendations. Financial confirmation
always bypasses presentation caching and repeats fresh signed native execution.
