## Result

History Undo used `GETPOST('undo_review', 'alphanum')`, an unsupported Dolibarr 24
filter. Its native fallback treated the nonce as another parameter name and
returned an empty value, rejecting a valid displayed review before mutation.
The controller now uses supported `aZ09`. The review consumer also rejects arrays
and malformed nonces with the normal review error, preserving single-use,
expiry, company, user, account and locked-state checks.

The new regression executes the actual controller-derived undo expression with
installed native GETPOST. The original filter reproduces the production failure;
the corrected filter passes. Previous mock request helpers ignored the filter
argument and therefore missed this defect.

The preceding historical quick-tax repair and legacy-source guard are recorded
in [1.20.52](DEPLOYMENT_1_20_52_20261115.md). Final production readback confirms
that repaired source remains pending, its warning is absent, and imported
amount/date/reference/feed evidence and account balances remain preserved.
